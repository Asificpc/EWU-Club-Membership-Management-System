# EWU Club Membership Management System

A PHP and MySQL based Club Membership Management System developed for East West University.

## Project Description

This system is designed to manage students, clubs, memberships, events, payments, and event registrations in an organized way.

## Key Features

- Admin Login

- User/Student Login

- Student Management

- Club Management

- Membership Management

- Event Management

- Payment Management

- Event Registration Management

- Create, Read, Update and Delete (CRUD) operations

- Role-based access for Admin and User/Student

## User Roles

### Admin

- Manage students

- Manage clubs

- Manage memberships

- Manage events

- Manage payments

- Manage event registrations

### User/Student

- View clubs

- View membership information

- View events

- View payments

## Technologies Used

- PHP

- MySQL

- XAMPP

- HTML

- CSS

- phpMyAdmin

## Database

The system uses MySQL as the relational database management system. The database contains tables for Admin, Student, Club, Membership, Event, Payment, and Event Registration.

## Project Structure

- PHP files — Application source code

- SQL file — Database structure and sample data

- CSS file — User interface styling

## How to Run

1. Install XAMPP.

2. Start Apache and MySQL.

3. Place the project folder inside the `htdocs` directory.

4. Import the provided SQL file into phpMyAdmin.

5. Open the project through `localhost` in a web browser.
